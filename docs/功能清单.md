# 月舒 WomenMoon 功能清单

> 本文档以**代码实现为准**编制，与 `功能梳理文档.md` 存在若干不一致处以本文档为准。
> 用途：作为 `docs/测试文档.md` 的输入，以及回归测试的范围基线。

- **项目**：月舒 WomenMoon — 女性经期健康管理 App
- **技术栈**：SwiftUI + SwiftData，iOS 17+，无后端
- **代码规模**：36 个 Swift 文件 / 约 8300 行
- **编制日期**：2026-09-21

## 一、导航结构

底部 5 个 Tab（`ContentView.swift:56-98`），每个 Tab 独立包一层 `NavigationStack`，主题色 `#E91E63`。

| Tab | 根视图 | 说明 |
|---|---|---|
| 首页 | `HomeView` | 仪表盘，聚合各模块入口 |
| 周期 | `CycleTrackerView` | 经期日历与记录 |
| 饮食 | `NutritionView` | 餐食与补剂 |
| 运动 | `ExerciseView` | 运动计划 |
| 我 | `ProfileView` | 个人资料与设置入口 |

**重要：以下页面都不是 Tab，必须经由二级入口进入。**

| 页面 | 唯一入口 |
|---|---|
| `AIAssistantView` | 首页右上角 `brain.head.profile` 按钮（sheet） |
| `EmotionTrackerView` | 首页快捷卡「记心情」 |
| `HealthMetricsView` | 首页快捷卡「记体重」；「我 → 健康数据」 |
| `SupplementDetailView` | 首页快捷卡「记补剂」；饮食页「今日补剂」 |
| `MedicalRecordsView` | 「我 → 病例管理」 |
| `SeasonalWellnessDietView` | 首页节气卡（sheet） |
| `SettingsView` | 「我 → 设置」 |
| `StressDetailView` | 首页压力指数卡 |
| ~~`SeasonalWellnessView`~~ | **无任何调用，整文件死代码** |
